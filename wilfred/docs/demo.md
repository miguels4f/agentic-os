# Demo narration

Run `uv run python examples/demo.py --output-root /tmp/new-wilfred-proof` for the credential-free
workflow demonstration. Add `--provider codex` for real agent calls with an authenticated Codex CLI.
`--provider fixture` tests orchestration only. Never present either offline mode as live-model proof.

Suggested narration:

1. “An ambiguous objective triggers material questions; every answer is recorded.”
2. “Three distinct supported problems select a workflow, one agent, and writer/reviewer agents.”
3. “Wilfred validates, generates Python, and runs it with network/side effects disabled.”
4. “A deliberate empty-input defect fails execution and blocks packaging.”
5. “A bounded repair changes defective source and its manifest; accepted components stay intact.”
6. “A child dies halfway through a write; resume recovers the prior state and retains evidence.”
7. “Two clean workflow builds have matching hashes; model outputs themselves are not deterministic.”
8. “A harmless protected host callback cannot run on a self-claim. The generated worker is separately
   isolated from that authority. A test signature is not human consent or a generated gate workflow.”

Inspect `workflow-proof.json`, `*-proof.json`, `provider-receipts.json`, and `product-version.json`.
Only observed live receipts and separate independent review can support completion claims.
See [CLI reference](agent-foundry/cli.md) and [Spanish recording script](portfolio/demo-script.md).
